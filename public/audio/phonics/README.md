# Phonics sound recordings

Drop the recorded letter-sound clips **in this folder**. The app plays them
automatically; any letter without a clip falls back to the built-in TTS voice,
so you can add them one at a time.

## Rules
- **One MP3 per sound**, named by the **letter in lower case**:
  `a.mp3`, `b.mp3`, … `z.mp3`, plus `ch.mp3`, `sh.mp3`, `th.mp3`, `ph.mp3`,
  `ng.mp3`, `nd.mp3`, `mb.mp3`, `nk.mp3` (34 files total).
- Record the **sound**, not the letter name ("sss", not "ess").
- Short (~0.3–0.8s), trimmed, volume-normalised, mono.

See `docs/phonics-recording-guide.md` for the full script and how to record on
a phone.
